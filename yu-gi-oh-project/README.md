# Yu-Gi-Oh Project

Este projeto é uma implementação simples do jogo de cartas Yu-Gi-Oh em Python. O objetivo é criar uma estrutura básica que simule a lógica do jogo, incluindo a criação de cartas, baralhos e a mecânica do jogo.

## Estrutura do Projeto

```
yu-gi-oh-project
├── src
│   ├── main.py       # Ponto de entrada da aplicação
│   ├── deck.py       # Classe que representa um baralho de cartas
│   ├── card.py       # Classe que representa uma carta do jogo
│   └── game.py       # Classe que gerencia a lógica do jogo
├── requirements.txt   # Dependências do projeto
└── README.md          # Documentação do projeto
```

## Instalação

Para instalar as dependências do projeto, execute o seguinte comando:

```
pip install -r requirements.txt
```

## Uso

Para iniciar o jogo, execute o arquivo `main.py`:

```
python src/main.py
```
