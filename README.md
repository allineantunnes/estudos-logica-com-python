## Estruturas principais que você verá

### Variáveis

Variáveis são espaços para guardar informações, como nomes, números e textos.

Exemplo:

```python
nome = "Ana"
idade = 20
```

### Condições

As condições ajudam o programa a tomar decisões.

Exemplo:

```python
idade = 18

if idade >= 18:
    print("Maior de idade")
```

### Loops

Loops servem para repetir ações várias vezes.

Exemplo:

```python
for i in range(3):
    print(i)
```

### Funções

Funções organizam o código e ajudam a reutilizar tarefas.

Exemplo:

```python
def saudacao():
    print("Olá, mundo!")

saudacao()
```
